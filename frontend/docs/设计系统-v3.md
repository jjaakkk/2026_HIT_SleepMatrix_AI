# 设计系统 —— SleepMatrix UI 重构（v4）

> 2026 秋季 · 从「深色工业控制台」到「安静的高级健康科技产品」。
> 参考：Eight Sleep / Oura（睡眠科技产品美学）+ awesome-design-md 8 篇设计文档
> （Apple / Linear / Stripe / Vercel / Raycast / Notion / Revolut / Resend）。

## 1. 视觉方向（v4）

| 维度 | 决策 |
|---|---|
| 气质 | 安静、精确、可信的临床级健康产品，而非"监控终端" |
| 亮度 | **浅色唯一**（冷调瓷白 parchment `#f5f5f7`），无明暗主题切换 |
| 主色 | 深松绿 `#0d7a6b`（松林夜色），避免 AI 紫；品牌渐变「夜色松绿 → 清晨琥珀」仅 logo/加载态 |
| 数据身份 | Turbo 热力图画布保留（深色衬底，收缩包裹不留黑块） |
| 语义色 | 区域六色沿用 `REGION_COLORS`；曲线系列色取自语义令牌 |

## 2. 布局（v4 · scale-to-fit）

- **固定 1920×1080 设计空间，整体等比缩放**铺满任意视口（0.5–1.5×）：
  左控制栏 236 / 中部双面板（热力图 + 压力趋势）/ 右洞察栏 300 / 底部行 280（气囊 + 部位受力排行）
- 任意分辨率（含 1366×768、Windows 缩放）**零内部滚动条、零溢出、零重叠**（audit 断言 + 后代越界检测）
- 渲染/量程控件置于热力图面板工具栏；侧栏仅保留数据源/回放/受测者/姿态/睡姿识别/图层/系统状态

## 3. 卡片规则（8 篇文档共识）

- 层级 = **表面明度阶梯**（#f5f5f7 → #fff → #fafafa → #f0f0f2）+ 1px hairline（#e5e5e8）
- **卡片零投影**；阴影只留给浮层（下拉/弹窗 `0 16px 48px -8px 16%`）
- 圆角统一：卡片 12px / 控件 8px / 浮层 16px / 胶囊 9999px，无中间值
- **面板内不嵌套带边框卡片**（睡姿卡为明度块）；悬停只提亮表面，不位移不加投影
- 字重仅 400/500/600（禁 700+ 与中间态）；数字 tabular-nums；分组标签正字距

## 4. 字体

- 西文/数字：Inter Variable（wght+opsz）
- **中文：MiSans（小米，免费商用）** —— 与 Inter 几何气质匹配；cn-font-split 按 unicode-range
  切块 + 浏览器按需加载（仓库内 303 个 woff2 子集，实际只加载用到的字符块）；字重重映射 400/500/600
- 仪表读数：IBM Plex Mono

## 5. 令牌（src/style.css）

- 色彩：`--bg/--surface-1..3/--border/--text-1..4/--accent` 全语义命名
- 圆角：6/8/12/16/999；阴影：仅 `--shadow-pop/--shadow-float`
- 动效：120/180/280/420ms；`ease-out/ease-spring/ease-in-out`；stagger 40ms
- 对比度：主文本 17.9:1，三级文本 4.5:1（WCAG AA+）

## 3. 组件架构

```
ui/Icon        24×24 统一描边图标集（~40 枚，currentColor，无外部依赖）
ui/UiBadge     状态徽章（neutral/accent/warning/danger/success + 呼吸脉冲）
ui/UiSegmented 分段控件 —— FLIP 定位滑动指示块（弹簧缓动），键盘天然可用
ui/UiSelect    自定义下拉 —— fixed 定位弹层（穿透 overflow 裁剪），↑↓/Enter/Esc 键盘导航
ui/UiSwitch    开关 —— role="switch"，按压形变反馈
ui/PanelCard   面板容器 —— 标题/副标题/图标/动作插槽
```

页面组合（v4.1）：`SidebarControls`（品牌 + 控制分组 + 系统状态）+ `HeatmapPanel`（热力图/渲染量程工具栏/图例/传输控制）
+ `MetricsChart`（**单一语义轴**：只画净压力口径——平均净压力面积线 + 最大净压力细线 + 区域虚线叠加；
异口径指标不进此图，接触面积趋势在指标卡 sparkline 呈现）+ `InsightPanel`（睡姿/指标）
+ `AirbagPanel`（**头部滑杆**位于标题与模拟信号徽章之间，点击行切换目标）+ `PoseTimeline` + 底部部位受力排行。

字号（v4.1 饱满化）：字号阶梯整体 +1~3px（12/13/14/15/17/20/27），字重 400/500/600，
仪表数字 tabular-nums；布局零滚动零越界由 audit 断言保障。

## 4. 动效清单（全部服务于因果与反馈）

| 动效 | 技术 | 意图 |
|---|---|---|
| 页面入场编排 | CSS keyframes + 逐级 delay（60/120/180/240ms） | 层级建立：先外壳后内容 |
| 指标数值滚动 | rAF + easeOutCubic（useTweenNumber） | 数据连续性，消除跳变 |
| 分段控件滑动块 | transform/width 过渡 + spring | 状态转移的空间连续感 |
| 下拉/弹层 | scale+translate 200ms | 来源方向（从触发器展开） |
| 播放按钮 | 图标 morph + 播放中脉冲环 | 进行中状态的持续反馈 |
| 播放头/进度 | scrubber 渐变填充 + 图表白线 | 时间定位 |
| 区域选中 | 矩形填充 pop + 排行行高亮 + 勾选动画 | 跨视图联动确认 |
| 悬浮 | 十字准星 + 数值浮卡（含该格 turbo 色） | 数据探查 |
| 脊柱线 | 开启时 draw-in 入场 | 图层状态变更 |
| 主题切换 | 全局 320ms 颜色过渡 + 图标旋转 morph | 状态变更的优雅确认 |

`prefers-reduced-motion` 下全部动画退化为即时状态。

## 7. 架构对齐（dev/arch）

- 目录：前端整体位于 `frontend/`（dev/arch 约定的成员 E 模块），后端合流时无路径冲突。
- 契约：`src/core/contracts/posture.json` = `shared/contracts/posture.json` vendored 副本；
  睡姿 ID/动作/镜像映射由契约驱动（contracts.ts 校验 + types.ts 只读消费），
  启动时经 `GET /api/contracts/posture` 同步远端契约，版本不一致 → 顶栏警告徽章。
- API：`src/core/api.ts` 封装 health / contracts / predict 三端点；dev/preview 代理 `/api` → 127.0.0.1:5000。
- 推理：睡姿卡支持「记录标签 / SVM 推理」双源，推理模式显示 label_zh + 置信度；
  离线自动降级标签模式，15s 静默重连。
- 口径：渲染层「弱力可视化」(γ=0.35) 与后端 `weak_area_enhance` 算法命名区分。
