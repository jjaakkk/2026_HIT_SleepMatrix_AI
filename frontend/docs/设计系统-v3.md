# 设计系统 v3 —— SleepMatrix UI 重构

> 2026 秋季 · 从「深色工业控制台」到「安静的高级健康科技产品」。
> 参考：Eight Sleep / Oura / Sleep Cycle（睡眠科技产品美学）、Linear / Vercel / Stripe（克制与动效哲学）。

## 1. 视觉方向（v3.1 · 松绿配色）

| 维度 | 决策 |
|---|---|
| 气质 | 安静、精确、可信的临床级健康产品，而非"监控终端" |
| 亮度 | 浅色优先（冷调瓷白），提供暗色主题（暖中性深色，区别于旧版冷蓝） |
| 主色 | 深松绿 `#0d7a6b`（松林夜色；暗色下玉青 `#35c2a4`），避免 AI 紫 |
| 品牌符号 | 「夜色松绿 → 清晨琥珀」渐变 + 睡眠波形，仅用于 logo / 加载态 |
| 数据身份 | Turbo 热力图画布保留（深色衬底，收缩包裹不留黑块） |
| 语义色 | 区域六色沿用 `REGION_COLORS`（橙/黄/青/粉/蓝/绿）；曲线系列色取自语义令牌随主题切换 |

## 2. 布局（v3.1）

- 左控制栏 236 / 中部双面板（热力图 + 压力趋势）/ 右洞察栏 300 / 底部行 280（气囊 + 部位受力排行）
- 目标：1920×1080 与 1600×1000 **零内部滚动条、零溢出、零重叠**（audit 断言）

## 2. 令牌（src/style.css）

- 色彩：`--bg / --surface-1..3 / --border / --text-1..3 / --accent` 全语义命名，`[data-theme='dark']` 覆盖
- 字体：Inter Variable（wght+opsz）/ IBM Plex Mono（仪表读数）/ Noto Sans SC（中文回退）
- 圆角：5/7/10/14/18/999，按语义（控件 < 卡片 < 面板）
- 阴影：4 级克制分层（xs/sm/md/lg/pop），浅色用暖灰、暗色用纯黑
- 动效：时长 120/200/320/520ms；缓动 `ease-out`（减速）/ `ease-spring`（微回弹）/ `ease-in-out`；入场位移 8–14px；stagger 45ms
- 对比度：主文本 17.3:1，三级文本 4.9:1（WCAG AA+）

## 3. 组件架构

```
ui/Icon        24×24 统一描边图标集（~40 枚，currentColor，无外部依赖）
ui/UiBadge     状态徽章（neutral/accent/warning/danger/success + 呼吸脉冲）
ui/UiSegmented 分段控件 —— FLIP 定位滑动指示块（弹簧缓动），键盘天然可用
ui/UiSelect    自定义下拉 —— fixed 定位弹层（穿透 overflow 裁剪），↑↓/Enter/Esc 键盘导航
ui/UiSwitch    开关 —— role="switch"，按压形变反馈
ui/PanelCard   面板容器 —— 标题/副标题/图标/动作插槽
```

页面组合：`TopBar`（品牌/状态/时钟/主题）+ `SidebarControls`（无卡片外壳的导航栏式分组）
+ `HeatmapPanel`（热力图/图例/传输控制）+ `InsightPanel`（睡姿/指标/排行）
+ `MetricsChart`（Canvas 趋势图）+ `AirbagPanel`（气囊）+ `PoseTimeline`（睡姿事件条）。

## 4. 动效清单（全部服务于因果与反馈）

| 动效 | 技术 | 意图 |
|---|---|---|
| 页面入场编排 | CSS keyframes + 逐级 delay（60/120/180/240ms） | 层级建立：先外壳后内容 |
| 指标数值滚动 | rAF + easeOutCubic（useTweenNumber） | 数据连续性，消除跳变 |
| 分段控件滑动块 | transform/width 过渡 + spring | 状态转移的空间连续感 |
| 下拉/弹层 | scale+translate 200ms | 来源方向（从触发器展开） |
| 播放按钮 | 图标 morph + 播放中脉冲环 | 进行中状态的持续反馈 |
| 播放头/进度 | scrubber 渐变填充 + 图表白线 | 时间定位 |
| 区域选中 | 矩形填充 pop + 排行行高亮 + 勾选动画 | 跨视图联动确认 |
| 悬浮 | 十字准星 + 数值浮卡（含该格 turbo 色） | 数据探查 |
| 脊柱线 | 开启时 draw-in 入场 | 图层状态变更 |
| 主题切换 | 全局 320ms 颜色过渡 + 图标旋转 morph | 状态变更的优雅确认 |

`prefers-reduced-motion` 下全部动画退化为即时状态。

## 7. 架构对齐（dev/arch）

- 目录：前端整体位于 `frontend/`（dev/arch 约定的成员 E 模块），后端合流时无路径冲突。
- 契约：`src/core/contracts/posture.json` = `shared/contracts/posture.json` vendored 副本；
  睡姿 ID/动作/镜像映射由契约驱动（contracts.ts 校验 + types.ts 只读消费），
  启动时经 `GET /api/contracts/posture` 同步远端契约，版本不一致 → 顶栏警告徽章。
- API：`src/core/api.ts` 封装 health / contracts / predict 三端点；dev/preview 代理 `/api` → 127.0.0.1:5000。
- 推理：睡姿卡支持「记录标签 / SVM 推理」双源，推理模式显示 label_zh + 置信度；
  离线自动降级标签模式，15s 静默重连。
- 口径：渲染层「弱力可视化」(γ=0.35) 与后端 `weak_area_enhance` 算法命名区分。
